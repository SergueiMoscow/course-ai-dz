## Способ 1: По формуле CRISPE (для стандартных LLM)
Подходит, когда нужно жестко задать формат, шаги и получить предсказуемый структурированный результат.
```text
Контекст: Мы готовим контент-план для личного блога эксперта по продуктивности.
Роль: Ты - креативный контент-стратег.
Цель: Придумать 5 нестандартных идей для поста про цифровой детокс (фокус и спокойствие). Никаких продаж.
Шаги:
1. Набросай 10 сырых идей с разными углами взгляда.
2. Отфильтруй их и оставь 5 самых цепляющих.
3. Для каждой из 5 идей напиши черновой заголовок и опиши суть в 1-2 предложениях.
Ограничения: Заголовок <= 7 слов. Тон - дружелюбный, экспертный. Строго без клише (избегай фраз "в нашем быстром мире", "успешные люди", "батарейка вашего телефона").
Примеры хороших заголовков: "Я выключила телефон на 24 часа. Вот что случилось", "Почему скроллинг ленты — это не отдых".
```
## Способ 2: Ролевой промпт с упором на негативные инструкции
Используем формулу роли из конспекта и лайфхак про 20-40% негативных инструкций (что модель НЕ должна делать).
```text
Ты - редактор популярного Telegram-канала о психологии и осознанности. Твоя зона ответственности: генерация идей для постов, которые вызывают желание сохранить их в избранное. Критерии качества: идеи должны быть глубокими, но легко читаться.

Задача: Придумать 5 идей для поста на тему "Цифровой детокс".

СТРОГО СОБЛЮДАЙ ПРАВИЛА (ЧЕГО ДЕЛАТЬ НЕЛЬЗЯ):
- Не предлагай идеи, которые сводятся к продаже чего-либо.
- Не используй банальные метафоры про "информационный мусор" или "перегруз мозга".
- Не делай заголовки в виде кликбейтных вопросов ("А вы тоже устаете от телефона?").
- Не придумывай идеи, которые требуют от читателя полной изоляции в лесу (это нереалистично).
```

## Способ 3: Few-Shot промптинг (через примеры)
Идеально для стабилизации формата и стиля, как указано в таблице конспекта. Даем 2 лаконичных примера и просим сделать по аналогии.
```text
Задача: Придумай 5 идей для поста про цифровой детокс. 

Вот примеры того, какой формат и стиль идей мне нужен:
Пример 1:
Угол: Личный провал
Заголовок: Мой месяц без соцсетей закончился срывом
Суть: Честный рассказ о том, как резкий отказ от гаджетов привел к тревоге, и почему нужен мягкий подход.

Пример 2:
Угол: Неочевидный факт
Заголовок: Скроллинг ленты обманывает ваш мозг
Суть: Объяснение дофаминовой петли на простых примерах, почему мы чувствуем усталость, а не отдых.

Придумай 5 новых идей в точно таком же формате (Угол, Заголовок, Суть). Тема постов - возвращение фокуса через цифровой детокс. Без продаж.
```
## Способ 4: Для Reasoning-моделей (o-серия, R1)
Применяем правила из блока "Reasoning-модели": краткость, делимитеры, отсутствие навязанного CoT и просьба не спешить.
```text
<задача>
Придумай 5 идей для поста на тему "Цифровой детокс и возвращение фокуса". Пост не должен содержать продаж.
</задача>

<критерии>
1. Идеи должны быть практическими, но не скучными.
2. Должны подходить для взрослой аудитории (25-45 лет).
</критерии>

Не спеши, возьми время на размышление. Выведи только финальный результат в виде списка из 5 пунктов: Заголовок — Суть поста.
```

## Способ 5: Сократовский промпт + Оценка уверенности
Используем технику, при которой модель перед генерацией оценивает полноту контекста и задает вопросы, если уверенность ниже 100%.
```text
Я хочу написать пост про "Цифровой детокс" (это не пост на продажу, а экспертный/развлекательный). Твоя задача — придумать для меня 5 идей.

Перед тем как начать генерировать идеи, ты должен оценить уровень понимания задачи по трем критериям (от 0 до 1):
1. Понимание целевой аудитории поста.
2. Понимание площадки, где будет опубликован пост (формат).
3. Понимание моего личного стиля общения.

Если хотя бы один из критериев ниже 1.0, НЕ придумывай идеи. Вместо этого задай мне 3 уточняющих вопроса, чтобы добить контекст до 100%. 
Если все критерии равны 1.0 — сразу генерируй 5 идей.
```
