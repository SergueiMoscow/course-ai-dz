```json
{
"Product": "Тепло-звукоизоляция",

"Area": "3.0sqm",

```

Во вложении прайс лист. Определи все ли тебе понятно для формирования JSON документа? Определи как корректно заполнять информацию, если нет 100% уверенности в каких то полях, заранее уточни у меня правила сбора информации. Проанализируй задачу и документы, потом пришли мне на согласование один товар, если меня устроит, подготовь весь файл.

Дополнительно: 
Поле Application Type может принимать 3 значения indoor, outdoor или both, информацию об этом берем в наименовании и описании.
Поле Наименование - краткое наимеонование в объединённых ячейках по вертикали. Описание находится в объединённых ячейках по горизонтали над группой товаров. Например:
Объединённая по горизонтали ячейка группы (описание):
"БЕЛТЕРМО-acustic–(BA) плотность- 240 кг/м3. Шумо и звукоизоляция внутри помещения стена/пол/потолок.  λ = 0,046 Вт/м*К       Состав: Древесина хвойных пород, MDI смола-4%, Парафин-2%" 
Здесь категория - БЕЛТЕРМО-acustic–(BA), остальное описание.

Если название или описание обрамлено в кавычки, или есть одна кавычка в начале или конце, такие кавычки убираем. Если же кавычки внутри текста несут какой-то смысл, то экранируем.
Длину, толщину, ширину пишем в миллиметрах, без разделителя дробей, только целые числа.

## Промпт для создания системного промпта (ChatGPT):
Ты должен подготовить большой системный промпт-инструкцию о работе ии агента менеджера по продажам компании изоплат, вот их сайт http://izoplat.su, изучи их сайт, их продукцию. Во вложении JSON файл с их актуальным прайс листом, я прикладываю его для лучшего понимания товаров с которыми будет работать агент, эта база будет добавлена ему в базу данных, по этому не нужно вставлять в инструкцию полный прайс. Этот агент будет принимать входящие запросы, иногда конкретные, где сразу интересуются конкретным товаром, а иногда нет и нужно будет подобрать товар. Всегда нужно расчитывать количество товара для клиента если он этого просит. Формировать запрос в базу он должен поняв какой тип применения товара наружный или внутренний, какая категория товара. Сам промпт инструкция должен быть в формате Markdown, где Заголовок это роль (чтоб ты не стал заголовком делать текст Промпт для агента менеджера...). Задай мне уточняющие вопросы, чтоб полностью понять задачу.
